# tiny-kana-free

The FREE preview kana videos for the Tiny Japanese website (the characters taught in the free lessons of Hiragana Starter and Katakana Starter).
Files live in `videos/` as `<hira|kata>-<key>.mp4` plus `.thumbnail.png`, served by GitHub Pages.
The rest of the kana videos are premium and are NOT in this repo.

Stroke order animation uses KanjiVG data (CC BY-SA 3.0, kanjivg.tagaini.net).
